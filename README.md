# Iñigo Casares · Diseño y desarrollo web

Portfolio de Iñigo Casares, diseñador y desarrollador web en Pamplona/Iruña. Creo webs para negocios locales que presentan sus servicios con claridad, funcionan bien en móvil y facilitan que un posible cliente contacte.

**[Ver el portfolio publicado](https://casares-06.github.io/inigo-casares-diseno-web/)**

## Qué encontrarás

- **PULSE:** aplicación web propia para explorar datos del historial de Spotify, con procesamiento privado en el navegador. [Ver proyecto](https://casares-06.github.io/PULSE/).
- **Conceptos de rediseño:** propuestas visuales independientes para mostrar cómo podría mejorar la presentación y la captación de contactos de un negocio. Son bocetos, no encargos ni webs oficiales de las empresas mostradas.
- **Servicios y proceso:** diseño responsive, estructura y contenido orientados a la claridad comercial, visibilidad local y un primer boceto gratuito antes de acordar alcance y precio.

Trabajo en castellano y euskera (nivel C1), con atención directa desde Pamplona/Iruña.
